# 验证范围

## 历史流程的记录

原移动版流程记录：两个备份共 1,528 个歌曲包，三难度谱面、封面和音源均完成提取；曾抽取 120 首比较并行与串行解密字节，抽取 40 首图片与系统解码器逐像素比较，并与已有曲库交叉检查音符位置和数量。

原 IFS 转换流程记录：与已有转换结果对比 3,130 个难度、约 158.9 万个音符。

以上是整理前流程的历史验证，不代表本仓库的每次提交都重跑这些私有样本，也不能证明适配所有游戏版本。样本、曲目清单、会话记录、设备信息及实际输出不随仓库发布。

## 当前可复现测试

`python3 -m unittest discover -s tests -v` 只使用运行时人工生成的数据，覆盖：

- 独立 Python 参考加密器产生的 BFCodec 密文，与 C 解密器对照；并发解密及短输出缓冲区拒绝。
- 单点、变 BPM、长押、极短长押和无效 TEMPO。
- IFS 分块越界与元数据路径校验。
- CgBI 通道、透明度、PNG 分块和解压长度。
- `.mc` / `.mcz` 音频、封面引用一致性，以及无音频模式。
- 合成移动备份和 IFS 的命令行提取、错误退出与既有输出保护。
- 不写入真实素材的公开内容检查。

音频外部编码器的可用性与实际备份版本需要使用者在自己的环境核对。仅做少量真实样本检查不能代替全曲库验证；CI 不接触真实游戏数据。
