# 街机 / PC 歌曲 IFS

适配已验证过的 jubeat 歌曲 `_msc.ifs`。输入是本地取得的资源目录；这份脚本不负责通用容器解包、程序解密、下载游戏或启动游戏。

## 定位与分块

8 位曲目 ID 为 `mid`，路径为：

```text
data/ifs_pack/d<mid前7位>/<mid>_msc.ifs
```

文件 `0x10` 处读取一个 BE32 基准偏移。基准前 60 字节是五条分块记录，每条 12 字节，前两个 BE32 分别是相对偏移和长度。区块地址为基准偏移加相对偏移。

| 区块 | 内容 |
|---|---|
| 0 | 完整 BGM，Konami BMP / OKI4S ADPCM |
| 1 | 试听音频；当前转换流程忽略 |
| 2 | EXT |
| 3 | ADV |
| 4 | BSC |

读入前限制 IFS 大小，读取各块前校验边界。极小的谱面块可能是未配信占位，返回失败。

## 谱面与时间轴

谱面块是 CP932 文本，记录一般为 `tick,命令,值`。关注 `TEMPO`、`PLAY`、`LONG`；`HAKU`、`MEASURE`、`END` 作为事件识别，但不输出为 playable note。

`TEMPO` 从 tick 0 开始，tick 频率为 300 Hz。BPM 值是 `60000000/BPM` 的整数截断，转换时寻找可回推到该整数的短小数。按 BPM 分段积分得到拍值，按 1/48 拍取整。

`LONG` 的位置、方向、长度和持续时间位段见 [移动版说明](mobile-format.md)。输出不把量化后同拍的长押降级成单点。

`.mc` 并非逐 tick 无损格式。若后续用途需要准确还原游戏事件时间，应保留原始输入，不要用 `.mc` 拍值代替原始 tick。

## 音频

Konami `BMP\0` 不是位图或 PCM；本工具处理该格式的 OKI4S ADPCM。读取采样率、声道数和样本数，再按半字节解码为 16-bit PCM。立体声时高 4 位为左声道、低 4 位为右声道。

默认只解码和转 Vorbis，不主动改变电平。可选 `--target-rms-db` 做 RMS 归一化；有损转换可能改变波形，建议保留原始输入。`--charts-only` 完全跳过音频处理。

## 元数据与打包

IFS 谱面块本身不能满足本脚本需要的全部标题、艺人、版本和等级信息，因此由调用者提供 `--songs` JSON。结构见 `examples/arcade-songs.example.json`；示例中的 ID 与标题均为虚构。

封面可由 `--covers` 指向自己的 PNG 目录。本仓库不提供官方曲目清单、封面或其他提取物。

元数据校验包含 ID、等级和版本目录。输出以曲目 ID 作文件名后缀，解决相同标题与大小写撞名。ZIP 在临时文件写完后才发布，失败不会留下看似完整的 `.mcz`，已有文件不覆盖。`--dry-run` 检查三难度是否能解析，但不测试音频编码器。
