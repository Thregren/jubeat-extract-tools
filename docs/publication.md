# 整理与发布范围

这是重新整理的独立仓库，没有复制原工作区或其 Git 历史。

保留内容：移动与街机格式解析方法、PAK/纹理/音库/命名IFS等额外导出源码、可参数化的批处理和本地报告工具、人工示例、合成数据测试与中文版本范围说明。

未纳入内容：

- 游戏程序、安装包、备份、原始 IFS / JBT，以及提取出的音乐、谱面、图片。
- 真实曲目清单、导入账本、逐曲报告、历史对话、截图和性能日志。
- 私人站点、服务器配置、部署流程、隐藏游玩模块或其入口。
- 原项目绝对路径、设备信息、访问凭证与个人邮箱。
- 一次性的曲库修复脚本，以及需要依赖旧仓库才能运行的导入脚本。
- 编译后的动态库、Python 缓存和运行产物。

整理中移除了默认下载目录搜索与旧仓库目录推断，并修正了 IV 注释、转码音频引用、散装谱面封面引用和错误返回码。增加了归档/图片预算、密文缓冲区检查和已有文件保护。

`PUBLISH_FILES.txt` 是可提交文件白名单。`scripts/check_public_tree.py` 同时检查白名单、忽略后的工作树和 Git 索引中的文本，阻止未登记的文件、个人路径、凭证格式或二进制内容。它是辅助检查，不能代替人工审阅；后续新增文件需明确加入清单。

许可证覆盖仓库代码与文档，不能据此授权传播游戏资源。名称和格式描述用于互操作与研究，项目没有官方关联。
